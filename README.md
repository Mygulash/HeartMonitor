# Heart rate monitor
In this project i dived into photoplethysmography which is quite interesting part of science. 
Long story short you shine light through your finger and thanks to spectroscopy we are able to detect the changes in light cause by blood on the other side of the finger.
It can be used as a fun project but also as a good enough source of your BPM data.
